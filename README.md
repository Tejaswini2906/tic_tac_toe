# Tic Tac Toe Game 🎮

A simple GUI-based Tic Tac Toe game built using Python and Tkinter.

---

## Features
- Player vs Player mode
- Interactive GUI
- Turn indicator
- Restart functionality

---

## Technologies Used
- Python
- Tkinter
